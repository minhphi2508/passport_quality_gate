# Output and Storage Policy

The SDK API and `BestFrameSelector` perform no automatic disk writes.

- preview/final analysis returns Python objects in memory;
- the best-frame buffer is RAM-only and bounded by both frame count and memory budget;
- `examples/webcam_demo.py` saves nothing unless `--save-dir` or `--log-jsonl` is explicitly provided;
- when `--save-dir` is used, each shutter event saves one selected image and one JSON result; no masks, heatmaps, crops, or overlays are generated by default;
- legacy research/debug writers remain archived and are not part of the integration-facing path.

Production applications should define their own retention/privacy policy for passport images and telemetry.
